## Problem

Given the `head` of a singly linked list, reverse the direction of every `next` pointer and return the new head (the node that used to be last).

Both an iterative and a recursive solution are expected to be discussed.

**Implement:** `def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]`

## Examples

**Example 1**

```text
Input:  head = [5, 8, 2, 7]
Output: [7, 2, 8, 5]
```

**Example 2**

```text
Input:  head = []
Output: []
```

An empty list stays empty.

**Example 3**

```text
Input:  head = [4]
Output: [4]
```

A single node is its own reversal.

## Constraints

- The list has between `0` and `5000` nodes.
- `-5000 <= Node.val <= 5000`

## Notes

- Lists are written in array notation, head first (e.g. `head = [1, 2, 3]`); `[]` is an empty list.
- Follow-up: can you do it in O(1) extra space and also recursively?
