## Problem

Given two strings `s` and `t`, return `true` if `t` is a rearrangement of the letters of `s` (same characters with the same counts, possibly in a different order), and `false` otherwise.

**Implement:** `def isAnagram(self, s: str, t: str) -> bool`

## Examples

**Example 1**

```text
Input:  s = "listen", t = "silent"
Output: true
```

Both use one each of l, i, s, t, e, n.

**Example 2**

```text
Input:  s = "apple", t = "paple"
Output: true
```

**Example 3**

```text
Input:  s = "aab", t = "abb"
Output: false
```

Same letters, but the counts of `a` and `b` differ.

## Constraints

- 1 <= s.length, t.length <= 5 * 10^4
- `s` and `t` contain only lowercase English letters.
