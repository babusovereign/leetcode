## Problem

Given an integer array `nums`, decide whether any value occurs more than once. Return `true` if at least one value is repeated, and `false` if every element is unique.

**Implement:** `def containsDuplicate(self, nums: list[int]) -> bool`

## Examples

**Example 1**

```text
Input:  nums = [7, 3, 9, 3]
Output: true
```

`3` appears at indices 1 and 3.

**Example 2**

```text
Input:  nums = [5, -2, 8]
Output: false
```

All three values are distinct.

**Example 3**

```text
Input:  nums = [0]
Output: false
```

A single element cannot be a duplicate.

## Constraints

- 1 <= nums.length <= 10^5
- -10^9 <= nums[i] <= 10^9

## Notes

- Is it acceptable to use O(n) extra memory, or should the array be sorted in place?
