## Problem

Given the `root` of a binary tree, return its node values grouped by depth: a list of levels from the root downward, where each level lists its values from left to right.

**Implement:** `def levelOrder(self, root: Optional[TreeNode]) -> list[list[int]]`

## Examples

**Example 1**

```text
Input:  root = [8, 4, 12, null, 6, 10]
Output: [[8], [4, 12], [6, 10]]
```

**Example 2**

```text
Input:  root = []
Output: []
```

**Example 3**

```text
Input:  root = [1]
Output: [[1]]
```

## Constraints

- The tree has between `0` and `2000` nodes.
- `-1000 <= Node.val <= 1000`

## Notes

- Trees are written in level-order with `null` for missing children (e.g. `root = [3, 1, 4, null, 2]`); `[]` is an empty tree.
