## Problem

A non-negative integer is stored as an array `digits`, most significant digit first, with no leading zeros (except for the number zero itself, stored as `[0]`). Add one to the number and return the result in the same format.

**Implement:** `def plusOne(self, digits: list[int]) -> list[int]`

## Examples

**Example 1**

```text
Input:  digits = [4, 3, 9]
Output: [4, 4, 0]
```

439 + 1 = 440; the carry ripples one place.

**Example 2**

```text
Input:  digits = [9, 9, 9]
Output: [1, 0, 0, 0]
```

All nines: the result is one digit longer.

**Example 3**

```text
Input:  digits = [0]
Output: [1]
```

## Constraints

- 1 <= digits.length <= 100
- 0 <= digits[i] <= 9
- No leading zeros, except for the number 0 itself.
