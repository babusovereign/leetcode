## Problem

Start with a positive integer `n` and repeatedly replace it with the sum of the squares of its decimal digits. If this process eventually reaches `1`, the number is called happy; otherwise it loops forever through a cycle that never contains `1`.

Return `true` if `n` is happy, otherwise `false`.

**Implement:** `def isHappy(self, n: int) -> bool`

## Examples

**Example 1**

```text
Input:  n = 7
Output: true
```

7 -> 49 -> 97 -> 130 -> 10 -> 1.

**Example 2**

```text
Input:  n = 4
Output: false
```

4 -> 16 -> 37 -> 58 -> 89 -> 145 -> 42 -> 20 -> 4, a cycle without 1.

**Example 3**

```text
Input:  n = 1
Output: true
```

## Constraints

- 1 <= n <= 2^31 - 1
