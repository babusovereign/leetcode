## Problem

Given an array `temperatures` of daily temperatures, return an array `answer` where `answer[i]` is the number of days you must wait after day `i` to see a strictly higher temperature. If no later day is warmer, `answer[i]` is `0`.

**Implement:** `def dailyTemperatures(self, temperatures: list[int]) -> list[int]`

## Examples

**Example 1**

```text
Input:  temperatures = [60, 58, 62, 62, 59, 65]
Output: [2, 1, 3, 2, 1, 0]
```

Day 2 (62) must wait until day 5 (65); an equal temperature on day 3 does not count.

**Example 2**

```text
Input:  temperatures = [80, 75, 70]
Output: [0, 0, 0]
```

**Example 3**

```text
Input:  temperatures = [50]
Output: [0]
```

## Constraints

- 1 <= temperatures.length <= 10^5
- 30 <= temperatures[i] <= 100
