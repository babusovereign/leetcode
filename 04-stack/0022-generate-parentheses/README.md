## Problem

Given an integer `n`, return every string of `n` pairs of parentheses that is well-formed (each `(` has a matching `)` later in the string, and no prefix contains more `)` than `(`). The strings may be returned in any order.

**Implement:** `def generateParenthesis(self, n: int) -> list[str]`

## Examples

**Example 1**

```text
Input:  n = 2
Output: ["(())", "()()"] (any order)
```

**Example 2**

```text
Input:  n = 1
Output: ["()"]
```

**Example 3**

```text
Input:  n = 3
Output: ["((()))", "(()())", "(())()", "()(())", "()()()"] (any order)
```

There are 5 well-formed strings with 3 pairs (the 3rd Catalan number).

## Constraints

- 1 <= n <= 8
