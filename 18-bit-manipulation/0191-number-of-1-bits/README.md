## Problem

Given a positive integer `n`, return the number of `1` bits in its binary representation (its population count, also called the Hamming weight).

**Implement:** `def hammingWeight(self, n: int) -> int`

## Examples

**Example 1**

```text
Input:  n = 13
Output: 3
```

13 is `1101` in binary.

**Example 2**

```text
Input:  n = 64
Output: 1
```

64 is `1000000`.

**Example 3**

```text
Input:  n = 2147483647
Output: 31
```

2^31 - 1 is thirty-one 1s.

## Constraints

- 1 <= n <= 2^31 - 1

## Notes

- Older versions of this problem passed `n` as an unsigned 32-bit value; in Java that means the input could look negative, so use an unsigned shift (`>>>`).
