## Problem

You are given a non-empty integer array `nums` in which every value appears exactly twice except for one value that appears exactly once. Return that unique value.

Your solution must run in linear time and use only constant extra space.

**Implement:** `def singleNumber(self, nums: list[int]) -> int`

## Examples

**Example 1**

```text
Input:  nums = [5, 3, 5]
Output: 3
```

**Example 2**

```text
Input:  nums = [-2, 8, 8, -2, 0]
Output: 0
```

**Example 3**

```text
Input:  nums = [9]
Output: 9
```

## Constraints

- 1 <= nums.length <= 3 * 10^4
- -3 * 10^4 <= nums[i] <= 3 * 10^4
- Exactly one element appears once; every other appears twice.
