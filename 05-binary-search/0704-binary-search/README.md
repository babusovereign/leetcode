## Problem

Given an integer array `nums` sorted in ascending order with no duplicates, and an integer `target`, return the index of `target` in `nums`, or `-1` if it is not present. The solution must run in O(log n) time.

**Implement:** `def search(self, nums: list[int], target: int) -> int`

## Examples

**Example 1**

```text
Input:  nums = [-7, -2, 0, 5, 11, 20], target = 11
Output: 4
```

**Example 2**

```text
Input:  nums = [-7, -2, 0, 5, 11, 20], target = 3
Output: -1
```

**Example 3**

```text
Input:  nums = [8], target = 8
Output: 0
```

## Constraints

- 1 <= nums.length <= 10^4
- -10^4 <= nums[i], target <= 10^4
- All values in `nums` are distinct.
- `nums` is sorted ascending.
- O(log n) time.
