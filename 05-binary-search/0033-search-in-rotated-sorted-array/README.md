## Problem

An ascending array of distinct integers may have been rotated at an unknown pivot (its tail moved to the front), giving `nums`. Given `nums` and an integer `target`, return the index of `target` in `nums`, or `-1` if it is absent. The solution must run in O(log n) time.

**Implement:** `def search(self, nums: list[int], target: int) -> int`

## Examples

**Example 1**

```text
Input:  nums = [30, 40, 50, 5, 10, 20], target = 10
Output: 4
```

**Example 2**

```text
Input:  nums = [30, 40, 50, 5, 10, 20], target = 35
Output: -1
```

**Example 3**

```text
Input:  nums = [6], target = 2
Output: -1
```

## Constraints

- 1 <= nums.length <= 5000
- -10^4 <= nums[i], target <= 10^4
- All values are distinct.
- `nums` is an ascending array possibly rotated.
- O(log n) time.
