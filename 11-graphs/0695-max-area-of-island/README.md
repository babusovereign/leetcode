## Problem

Given an `m x n` binary grid where `1` is land and `0` is water, an island is a set of land cells connected 4-directionally (up, down, left, right). The area of an island is its number of cells. Return the largest island area, or `0` if there is no land.

**Implement:** `int maxAreaOfIsland(int[][] grid)`

## Examples

**Example 1**

```text
Input:  grid = [[1, 1, 0, 0, 1], [0, 1, 0, 1, 1], [0, 0, 0, 0, 1], [1, 0, 1, 0, 0]]
Output: 4
```

The island on the right edge has 4 cells; the top-left island has 3.

**Example 2**

```text
Input:  grid = [[0, 0, 0]]
Output: 0
```

No land at all, so the answer is 0.

## Constraints

- 1 <= m, n <= 50
- Each cell is `0` or `1`.
