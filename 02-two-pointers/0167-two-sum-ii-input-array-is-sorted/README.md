## Problem

Given a 1-indexed integer array `numbers` sorted in non-decreasing order and an integer `target`, find two elements at different positions that add up to `target`. Return their positions as `[index1, index2]` with `index1 < index2`, using 1-based indexing. Exactly one solution exists, and the solution must use only O(1) extra space.

**Implement:** `def twoSum(self, numbers: list[int], target: int) -> list[int]`

## Examples

**Example 1**

```text
Input:  numbers = [1, 3, 4, 8, 11], target = 7
Output: [2, 3]
```

`3 + 4 = 7`; they sit at 1-based positions 2 and 3.

**Example 2**

```text
Input:  numbers = [-5, -2, 0, 7], target = -7
Output: [1, 2]
```

**Example 3**

```text
Input:  numbers = [2, 2], target = 4
Output: [1, 2]
```

## Constraints

- 2 <= numbers.length <= 3 * 10^4
- -1000 <= numbers[i] <= 1000
- `numbers` is sorted in non-decreasing order.
- Exactly one solution exists.
- O(1) extra space.

## Notes

- Note the answer is 1-indexed, unlike the original Two Sum.
