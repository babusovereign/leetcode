## Problem

Given two strings `text1` and `text2`, return the length of the longest sequence of characters that is a subsequence of both. A subsequence is formed by deleting zero or more characters without reordering the rest. If they share no characters, return `0`.

**Implement:** `def longestCommonSubsequence(self, text1: str, text2: str) -> int`

## Examples

**Example 1**

```text
Input:  text1 = "acdbe", text2 = "abde"
Output: 3
```

"ade" or "abe".

**Example 2**

```text
Input:  text1 = "xyz", text2 = "abc"
Output: 0
```

No characters in common.

**Example 3**

```text
Input:  text1 = "river", text2 = "river"
Output: 5
```

Identical strings.

## Constraints

- 1 <= text1.length, text2.length <= 1000
- Both strings are lowercase English letters.
