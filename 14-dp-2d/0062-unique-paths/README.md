## Problem

A robot starts in the top-left cell of an `m` x `n` grid and wants to reach the bottom-right cell. It may only move one cell right or one cell down at each step. Return the number of distinct paths it can take.

**Implement:** `def uniquePaths(self, m: int, n: int) -> int`

## Examples

**Example 1**

```text
Input:  m = 3, n = 3
Output: 6
```

Choose which 2 of the 4 moves are "down": C(4, 2).

**Example 2**

```text
Input:  m = 1, n = 5
Output: 1
```

Edge case: a single row allows only one path.

**Example 3**

```text
Input:  m = 4, n = 3
Output: 10
```

## Constraints

- 1 <= m, n <= 100
- The answer is at most 2 * 10^9.
