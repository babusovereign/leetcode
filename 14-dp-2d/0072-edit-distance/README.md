## Problem

Given two strings `word1` and `word2`, return the minimum number of single-character operations needed to turn `word1` into `word2`. The allowed operations are inserting a character, deleting a character, and replacing one character with another.

**Implement:** `def minDistance(self, word1: str, word2: str) -> int`

## Examples

**Example 1**

```text
Input:  word1 = "sunday", word2 = "saturday"
Output: 3
```

Insert "a" and "t", replace "n" with "r".

**Example 2**

```text
Input:  word1 = "", word2 = "abc"
Output: 3
```

Edge case: insert every character.

**Example 3**

```text
Input:  word1 = "abc", word2 = "abc"
Output: 0
```

## Constraints

- 0 <= word1.length, word2.length <= 500
- Both strings are lowercase English letters.
