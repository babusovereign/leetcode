## Problem

Given a string `s`, count how many of its substrings are palindromes. Substrings are counted by position, so two equal substrings at different start or end indices are counted separately.

**Implement:** `def countSubstrings(self, s: str) -> int`

## Examples

**Example 1**

```text
Input:  s = "aba"
Output: 4
```

"a", "b", "a", and "aba".

**Example 2**

```text
Input:  s = "aaaa"
Output: 10
```

4 of length 1, 3 of length 2, 2 of length 3, 1 of length 4.

**Example 3**

```text
Input:  s = "q"
Output: 1
```

Edge case: a single character.

## Constraints

- 1 <= s.length <= 1000
- `s` consists of lowercase English letters.
