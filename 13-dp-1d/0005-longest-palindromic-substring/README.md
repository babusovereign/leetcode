## Problem

Given a string `s`, return a longest contiguous substring of `s` that reads the same forwards and backwards. If several substrings tie for the maximum length, returning any one of them is accepted.

**Implement:** `def longestPalindrome(self, s: str) -> str`

## Examples

**Example 1**

```text
Input:  s = "bananas"
Output: "anana"
```

**Example 2**

```text
Input:  s = "xyz"
Output: "x"
```

Every single character is a palindrome; "y" or "z" are also accepted.

**Example 3**

```text
Input:  s = "abba"
Output: "abba"
```

Even-length palindrome: the center is between two characters.

## Constraints

- 1 <= s.length <= 1000
- `s` consists of digits and English letters.

## Notes

- Substring means contiguous, unlike a subsequence.
