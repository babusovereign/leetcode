## Problem

You are at the bottom of a staircase with `n` steps. On each move you may go up either 1 step or 2 steps. Return the number of distinct sequences of moves that land you exactly on the top step.

**Implement:** `def climbStairs(self, n: int) -> int`

## Examples

**Example 1**

```text
Input:  n = 4
Output: 5
```

1+1+1+1, 1+1+2, 1+2+1, 2+1+1, 2+2.

**Example 2**

```text
Input:  n = 1
Output: 1
```

Edge case: a single 1-step move.

**Example 3**

```text
Input:  n = 6
Output: 13
```

## Constraints

- 1 <= n <= 45

## Notes

- Order of moves matters: 1+2 and 2+1 count as different ways.
