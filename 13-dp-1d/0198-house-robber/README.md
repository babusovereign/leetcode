## Problem

Houses along a street each hold some amount of cash, given as the non-negative array `nums`. You want to collect as much as possible, but you cannot take from two houses that are next to each other. Return the largest total you can collect.

**Implement:** `def rob(self, nums: list[int]) -> int`

## Examples

**Example 1**

```text
Input:  nums = [3, 10, 4, 8]
Output: 18
```

Take houses 1 and 3: 10 + 8.

**Example 2**

```text
Input:  nums = [7]
Output: 7
```

Edge case: one house.

**Example 3**

```text
Input:  nums = [5, 1, 1, 5]
Output: 10
```

Take the first and last houses; skipping two in a row is allowed.

## Constraints

- 1 <= nums.length <= 100
- 0 <= nums[i] <= 400
