## Problem

Given an integer array `nums`, return the length of its longest strictly increasing subsequence. A subsequence keeps the original order but may skip elements.

**Implement:** `def lengthOfLIS(self, nums: list[int]) -> int`

## Examples

**Example 1**

```text
Input:  nums = [4, 10, 4, 3, 8, 9]
Output: 3
```

For example 4, 8, 9 (or 3, 8, 9).

**Example 2**

```text
Input:  nums = [5, 5, 5]
Output: 1
```

Edge case: equal values do not count as increasing.

**Example 3**

```text
Input:  nums = [1, 3, 2, 4, 3, 5]
Output: 4
```

## Constraints

- 1 <= nums.length <= 2500
- -10^4 <= nums[i] <= 10^4
