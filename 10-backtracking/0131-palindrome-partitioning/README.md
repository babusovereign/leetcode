## Problem

Given a string `s`, split it into pieces so that every piece is a palindrome, and return every such way of splitting it. Each result is a list of substrings that concatenate back to `s` in order; the results may be returned in any order.

**Implement:** `List<List<String>> partition(String s)`

## Examples

**Example 1**

```text
Input:  s = "abba"
Output: [["a", "b", "b", "a"], ["a", "bb", "a"], ["abba"]] (any order)
```

**Example 2**

```text
Input:  s = "xyz"
Output: [["x", "y", "z"]]
```

No substring longer than one character is a palindrome.

**Example 3**

```text
Input:  s = "z"
Output: [["z"]]
```

## Constraints

- 1 <= s.length <= 16
- `s` contains only lowercase English letters.
