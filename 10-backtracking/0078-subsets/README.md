## Problem

Given an array `nums` of distinct integers, return every possible subset (the power set). The result must not contain the same subset twice, and the subsets may be returned in any order; the empty set is always included.

**Implement:** `List<List<Integer>> subsets(int[] nums)`

## Examples

**Example 1**

```text
Input:  nums = [4, 7, 1]
Output: [[], [4], [7], [1], [4, 7], [4, 1], [7, 1], [4, 7, 1]] (any order)
```

3 distinct elements give 2^3 = 8 subsets, including the empty set.

**Example 2**

```text
Input:  nums = [-3]
Output: [[], [-3]] (any order)
```

## Constraints

- 1 <= nums.length <= 10
- -10 <= nums[i] <= 10
- All values in `nums` are distinct.
