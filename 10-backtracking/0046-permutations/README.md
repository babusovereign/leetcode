## Problem

Given an array `nums` of distinct integers, return every possible ordering (permutation) of its elements. The permutations may be returned in any order.

**Implement:** `List<List<Integer>> permute(int[] nums)`

## Examples

**Example 1**

```text
Input:  nums = [5, 0, -1]
Output: [[5, 0, -1], [5, -1, 0], [0, 5, -1], [0, -1, 5], [-1, 5, 0], [-1, 0, 5]] (any order)
```

**Example 2**

```text
Input:  nums = [8]
Output: [[8]]
```

## Constraints

- 1 <= nums.length <= 6
- -10 <= nums[i] <= 10
- All values are distinct.
