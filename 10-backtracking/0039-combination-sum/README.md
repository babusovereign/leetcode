## Problem

Given an array `candidates` of distinct positive integers and a positive integer `target`, return all unique combinations of candidates that add up to `target`. Each candidate may be chosen an unlimited number of times. Two combinations are the same if they use each number the same number of times (order doesn't matter); return them in any order.

**Implement:** `List<List<Integer>> combinationSum(int[] candidates, int target)`

## Examples

**Example 1**

```text
Input:  candidates = [3, 5, 2], target = 8
Output: [[2, 2, 2, 2], [3, 3, 2], [3, 5]] (any order)
```

Each number may be used any number of times; [3, 5] and [5, 3] count as the same combination.

**Example 2**

```text
Input:  candidates = [4, 6], target = 5
Output: []
```

No combination works.

**Example 3**

```text
Input:  candidates = [7], target = 7
Output: [[7]]
```

## Constraints

- 1 <= candidates.length <= 30
- 2 <= candidates[i] <= 40
- All candidates are distinct.
- 1 <= target <= 40
