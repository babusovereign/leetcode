## Problem

Given a string `s`, return the length of the longest contiguous substring in which no character appears more than once.

**Implement:** `def lengthOfLongestSubstring(self, s: str) -> int`

## Examples

**Example 1**

```text
Input:  s = "abcbdea"
Output: 5
```

`"cbdea"` has five distinct characters.

**Example 2**

```text
Input:  s = "zzzz"
Output: 1
```

**Example 3**

```text
Input:  s = ""
Output: 0
```

## Constraints

- 0 <= s.length <= 5 * 10^4
- `s` may contain English letters, digits, symbols, and spaces.

## Notes

- A substring must be contiguous; a subsequence does not count.
