## Problem

You are given an array `prices` where `prices[i]` is a stock's price on day `i`. You may buy one share on some day and sell it on a strictly later day. Return the largest profit achievable from a single such transaction, or `0` if no profitable trade exists.

**Implement:** `def maxProfit(self, prices: list[int]) -> int`

## Examples

**Example 1**

```text
Input:  prices = [9, 4, 6, 2, 8, 3]
Output: 6
```

Buy at 2 (day 3) and sell at 8 (day 4).

**Example 2**

```text
Input:  prices = [8, 6, 5, 1]
Output: 0
```

Prices only fall, so the best choice is not to trade.

**Example 3**

```text
Input:  prices = [4]
Output: 0
```

## Constraints

- 1 <= prices.length <= 10^5
- 0 <= prices[i] <= 10^4
