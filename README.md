# LeetCode: the NeetCode 150, by pattern

Practice repo for coding interviews. The 150 problems are grouped into 18 patterns, in the order of the [NeetCode roadmap](https://neetcode.io/roadmap). Each problem has its own folder with the question in `README.md`; solutions go in the same folder.

## Layout

```text
01-arrays-hashing/
  README.md                    # the pattern and its problems
  0217-contains-duplicate/
    README.md                  # the question
    Solution.java              # your solution(s)
    solution.py
```
